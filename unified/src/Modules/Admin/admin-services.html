Cron Service Management
Pause/Resume services or enable/disable on boot. Pausing stops the service but keeps it enabled for boot.
Status States:
• Database Enabled = Module enabled in settings (MotorolaPage, SerialPage, etc.)
• Running = Systemd service is currently active
• Enabled for Boot = Service will start automatically on reboot

Actions:
• Pause = Stop service temporarily (keeps enabled for boot and database)
• Resume = Start a paused service
• Enable/Disable Boot = Control whether service starts on reboot

Alarms: If Database Enabled = Yes but Running = No, an alarm should be raised.
